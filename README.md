# 🌆 «Аким на 5 часов» — AI-симулятор управления городом

## 📌 О проекте

**«Аким на 5 часов»** — это интерактивный AI-симулятор, который позволяет любому жителю почувствовать себя акимом города: распределить городской бюджет между ключевыми направлениями и мгновенно увидеть последствия своих решений.
