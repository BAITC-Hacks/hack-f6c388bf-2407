# AI-модуль

AI объясняет уже рассчитанный результат учебного симулятора. Провайдер — OpenAI;
DeepSeek был источником чернового предложения, его числа и код не приняты как истина.
Публичный интерфейс: `await explain_scenario(payload, include_ai_analysis=True)`.
Вход типизирован, неизвестные поля не отправляются: при ошибке валидации возвращается
None. Игровые правила и числовую корректность проверяет движок backend.

Модель задаёт OPENAI_MODEL. Используется Responses API с Pydantic Structured Outputs,
без temperature и без автоматической замены модели. SDK — дополнительная зависимость
`ai` в pyproject.toml. Настройки читаются из окружения и корневого .env, ключ скрыт
в repr и не включается в промпт, логи или кэш. Ответ у провайдера не сохраняется
как объект Responses (`store=False`); это не обещание отсутствия всех служебных логов провайдера.

Таймаут по умолчанию 15 секунд на запрос, без повторов; ошибки API, отказ модели,
незавершённый ответ, невалидный вход/выход и отсутствие настроек дают None.
Отмена HTTP-запроса не подавляется. `include_ai_analysis=False` не обращается к AI
и не возвращает старый кэш. Настройки: AI_TIMEOUT_SECONDS, AI_MAX_OUTPUT_TOKENS
(по умолчанию 1600), AI_CACHE_TTL_SECONDS (300; 0 отключает кэш).

Кэш в памяти процесса: максимум 128 успешных ответов, TTL; ключ включает весь вход,
промпт, схему и модель. Числа изменились — нужен новый ответ. При выдаче создаётся
копия, ошибки не кэшируются. Между workers кэш не общий; параллельные одинаковые
запросы могут вызвать модель несколько раз. Для демо этого достаточно.

Structured Outputs проверяет форму ответа, но не гарантирует истинность текста.
Промпт запрещает новые числа и неподтверждённые выводы; качество реального ответа
нужно оценить на демо-сценариях. Автоматического доказательства фактов здесь нет.

Исправления к черновику: контракт HTTP сохранён; ошибка — `domain_limit` с `message`;
для M7/M8 используется доля 5/8, для M10/M12 — 7/8; синергия добавляется отдельно.
M5 улучшает воздух и ЖКХ, не озеленение. Примеры пересчитываются скриптом
`tools/generate_ai_examples.py` для одного фиксированного набора, не моделью.

Инструкция подключения: `apps/api/src/akim_api/ai/README.md`.
Основание реализации: [официальная документация OpenAI](https://developers.openai.com/api/docs/guides/structured-outputs).
