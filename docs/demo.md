# Сценарий демонстрации

Примеры — синтетические данные учебной модели, не прогноз для реальной Астаны.
`score_success_with_ai.json` содержит редакционный текст для UI, не живой ответ API.

1. Показать бюджет 100 и исходный score 52.56.
2. Выбрать M7, M8, M10 в Нуре, общегородскую M12 и M5 в Сарыарке.
   Запрос сохранён в contracts/examples/score_request.json.
3. Показать расход 95, остаток 5. Объяснить задержку реализации мер:
   S1 Нуры 38 → 48, S2 35 → 43.75, B1 55 → 67.5 с синергией M10+M12.
4. Сверить score и показатели с score_success_no_ai.json. Показать AI-разбор:
   социальные улучшения, оставшиеся проблемы транспорта, ограничения рекомендаций.
5. Повторить с include_ai_analysis=false: расчёт тот же, AI-разбор отсутствует.
6. Выбрать три социальные меры: backend должен вернуть 422/domain_limit без score.

Прогноз и итоговый расчёт доступны через backend API. Без настроенного ключа
симулятор показывает детерминированное объяснение и помечает AI как отключённый;
с `AI_PROVIDER=openai`, `OPENAI_API_KEY` и `OPENAI_MODEL` добавляется разбор модели.
Для проверки полного маршрута запустить backend и frontend по инструкциям в корневом README.
